# tele v1.1.0

This minor release adds a first-class managed-bot factory. An authenticated user
can check bot usernames and create bots that remain user-owned while delegating
their control plane to a dedicated Bot Management Mode manager bot.

The new `tele bots` surface:

- verifies and stores a manager credential through hidden input, stdin, or a
  named environment variable
- checks usernames and creates manager-owned bots through the authenticated
  MTProto user session
- keeps a private, atomic, profile-scoped local bot inventory with no tokens
- retrieves, synchronizes, and explicitly rotates child tokens through the
  manager Bot API
- stores manager and child credentials only in the supported secret backend
- emits stable `tele/v1` JSON and JSONL contracts without credential material
- distinguishes rejected, outcome-unknown, and confirmed-but-locally-incomplete
  operations so agents do not blindly duplicate creation or token rotation

Existing v1 commands and machine-result shapes are unchanged. The release adds
new allowlisted result shapes for the new commands.
