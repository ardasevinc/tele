# tele v1.2.1

This patch release fixes a false macOS doctor failure after migration to the
catalog-backed `keychain-v1` secret backend. The native Keychain store already
implemented authoritative catalog diagnostics, but the production lazy secret
store wrapper did not forward that capability. `tele doctor` therefore
reported `native catalog diagnostics are unavailable` even while secret reads,
session decryption, Telegram connectivity, and authorization all succeeded.

The lazy wrapper now forwards native catalog diagnostics. Regression coverage
exercises both the wrapper contract and the complete doctor path that exposed
the issue during manual Mac QA.

Secret formats, migration behavior, the `tele/v1` machine schema, updater
semantics, and platform support are unchanged.
