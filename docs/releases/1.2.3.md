# tele v1.2.3

This security maintenance release rebuilds Tele with Go 1.26.10, including
the crypto/x509 distrust update for compromised intermediate certificates
(GO-2026-6809 / CVE-2026-111943). The minimum source-build toolchain is now
Go 1.26.10; users on the Go 1.27 line should use Go 1.27.3 or later.

The official macOS binaries retain the existing Developer ID identity,
designated requirement, hardened runtime and notarization policy. No profile,
Keychain or vault migration is needed when upgrading from the official 1.2.2
release. Telegram command contracts and credential storage are unchanged.
